# JavaMile 0.3.1 — GitHub Pages root release

Extract this ZIP. Upload its contents directly into the repository root, replacing the existing index.html, app.js, style.css, data.js and location.js. Include nearby.js and the assets folder. Do not place these files inside a dist folder or another JavaMile folder.

GitHub Pages should use the main branch and / (root), matching your current setup. After deployment, refresh the page. The footer must say JavaMile 0.3.1 · Nearby cafés.

Allow browser location, then select Allow nearby café search. Approximate coordinates are sent to OpenStreetMap Overpass only after that consent. Results are community-mapped cafés ordered by straight-line distance, not guaranteed complete business listings. Full drink menus, verified prices and personalized real drink recommendations still require another data source. The normal screens do not fall back to fictional cafés.

No API key is needed for the public Overpass lookup. Service availability and coverage vary. External live lookup was not verified from the build environment; syntax and source checks passed. No credentials included.
